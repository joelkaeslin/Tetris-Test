# 🎮 TETRIS – Mein eigenes Spiel

Willkommen bei meinem Tetris-Projekt!

Hier kannst du mein selbst programmiertes Tetris-Spiel herunterladen oder den Quellcode anschauen.

---

## 🎮 1. Spiel herunterladen

Du möchtest Tetris spielen? Dann lade hier die fertige Windows-Version herunter.

**[⬇️ TETRIS-SPIEL HERUNTERLADEN](https://github.com/joelkaeslin/Tetris-Test/releases/download/v1.0/Tetris-Spiel.zip)**

- Für Windows
- Fertig zum Spielen
- ZIP-Datei herunterladen und entpacken
- Anschliessend `Spiel.exe` starten

Da dieses Projekt ein kostenloses Hobby-Projekt ist, besitzt die `.exe`-Datei kein teures digitales Entwickler-Zertifikat. Deshalb zeigt Windows beim ersten Start eine Sicherheitswarnung an (*„Der Computer wurde durch Windows geschützt“*).

**So startest du das Spiel trotzdem:**
1. Klicke im blauen Fenster auf **Weitere Informationen**.
2. Klicke anschließend unten auf **Trotzdem ausführen**.
