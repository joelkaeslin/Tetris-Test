## ⚠️ Hinweis beim Starten (Windows SmartScreen)

Da dieses Projekt ein kostenloses Hobby-Projekt ist, besitzt die `.exe`-Datei kein teures digitales Entwickler-Zertifikat. Deshalb zeigt Windows beim ersten Start eine Sicherheitswarnung an (*„Der Computer wurde durch Windows geschützt“*).

**So startest du das Spiel trotzdem:**
1. Klicke im blauen Fenster auf **Weitere Informationen**.
2. Klicke anschließend unten auf **Trotzdem ausführen**.
